## [1.0.0](https://github.com/Walkaisa/Aegis/releases/tag/v1.0.0) (2026-09-19)

First public release.

### Features

- OpenID Connect provider built on [oidc-provider](https://github.com/panva/node-oidc-provider) that works with any standard client, from Auth.js to oauth2-proxy.
- Applications with logos, exact redirect URIs, scopes per application, rotatable client secrets and a per-application PKCE policy (S256 always required for public clients).
- Accounts with roles, profile pictures, access to applications and sessions that can be viewed and revoked at any time.
- Two-factor authentication with authenticator apps and recovery codes, for the administration and every application.
- Searchable audit log of every sign-in and change, with configurable retention.
- Guided first-time setup, light and dark mode, English and German, fully responsive interface.
- Argon2id password hashing and encryption at rest for signing keys and client secrets.
- Single Docker image `ghcr.io/walkaisa/aegis` for `linux/amd64` and `linux/arm64`, applying database migrations on startup.
